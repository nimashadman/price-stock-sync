=== بروزرسانی کالا با نرم‌افزار حسابداری ===

پلاگین بروزرسانی خودکار قیمت و موجودی کالاهای ووکامرس از طریق فایل JSON نرم‌افزار حسابداری.
اتصال مستقیم API در حال توسعه است و برای پیاده‌سازی کاستوم می‌توانید پیام بدهید:
shadman.nima@gmail.com

توسعه‌دهنده: نیما شادمان
وب‌سایت: https://nimashadman.ir
مخزن گیت‌هاب: https://github.com/nimashadman/price-stock-sync

نصب:
1. پوشه price-stock-sync را zip کرده و از مسیر افزونه‌ها > افزودن > بارگذاری افزونه، آپلود و فعال کنید.
   (یا کل پوشه را مستقیماً داخل wp-content/plugins آپلود کنید.)
2. پلاگین نیاز به ووکامرس فعال دارد.

تنظیمات (منوی بروزرسانی کالا در ادمین):
- مسیر فایل JSON: پیش‌فرض روی
  /home/h353344/domains/pharmafit.ir/RainDataSenderExport.json
  تنظیم شده؛ در صورت نیاز تغییر دهید.
- اجرای زمان‌بندی‌شده (Cron): فعال/غیرفعال و فاصله زمانی به دقیقه قابل تنظیم است.
- دکمه «اجرای همگام‌سازی هم‌اکنون» برای اجرای دستی فوری.
- چراغ وضعیت بروزرسانی کالا در نوار بالای وردپرس نمایش داده می‌شود:
  سبز یعنی زمان‌بندی فعال/در حال اجراست، قرمز یعنی خاموشی، قطع کران، دیرکرد یا خطای آخرین اجرا.
- در صفحه تنظیمات، بخش «وضعیت زمان‌ها» زمان دقیق آخرین آپلود/تغییر فایل JSON روی سرور،
  آخرین شروع همگام‌سازی، آخرین بروزرسانی موفق و اجرای بعدی کران را نمایش می‌دهد.

منطق همگام‌سازی:
- هر آیتم در فایل JSON بر اساس فیلد Barcode با فیلد SKU محصول/تنوع در ووکامرس مچ می‌شود.
- فقط دو فیلد بروزرسانی می‌شوند: قیمت (Price -> قیمت معمولی/regular price) و موجودی (StockQuantity -> stock).
- قیمت Price به‌صورت خام (بدون کسر CurrentDiscount) ثبت می‌شود.
- اگر موجودی یک تنوع به‌صورت مستقل مدیریت نشود (manage stock در سطح والد فعال باشد)،
  موجودی روی محصول والد بروزرسانی می‌شود.
- بروزرسانی فقط زمانی انجام می‌شود که مقدار جدید با مقدار فعلی در ووکامرس متفاوت باشد؛
  محصولات بدون تغییر، لمس نمی‌شوند.
- بارکدهای تکراری در فایل: آخرین مقدار در فایل برای آن بارکد استفاده می‌شود.
- آیتم‌هایی با Barcode خالی نادیده گرفته می‌شوند.

لاگ:
- هر اجرا (دستی یا کرون) یک رکورد run در دیتابیس ثبت می‌کند (تعداد کل آیتم، مچ‌شده، بروزرسانی‌شده، خطا).
- جزئیات هر تغییر (SKU، شناسه محصول، فیلد، مقدار قبل/بعد) قابل مشاهده در صفحه
  «لاگ اجراها > جزئیات» است.

نکات:
- روی کاتالوگ‌های بزرگ، اجرای دستی از طریق ادمین ممکن است طول بکشد؛
  در این موارد بهتر است فقط به اجرای کرون تکیه کنید.
- هنگام غیرفعال کردن پلاگین، رویداد کرون پاک می‌شود اما جداول لاگ
  (wp_rpss_runs و wp_rpss_log) برای حفظ تاریخچه حذف نمی‌شوند.
- اگر رویداد کرون به هر دلیل از وردپرس حذف شود، پلاگین به‌صورت خودکار آن را دوباره ثبت می‌کند.
